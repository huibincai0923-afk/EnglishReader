# English Reader

A browser-based EPUB reader MVP.

Features:
- Import EPUB books locally in your browser
- Read chapters
- Previous/next chapter navigation
- IELTS vocabulary highlighting
- Click highlighted words for definitions
- Save reading position locally
- Dark mode

## Run locally

This version is intentionally dependency-free so it can be uploaded directly to a static host.

1. Open `index.html` in a modern browser.
2. Click **Add EPUB** and choose an `.epub` file.

For best results, use a simple local HTTP server or deploy the folder to Vercel/Netlify/GitHub Pages.

## Privacy

The EPUB is processed in the browser. The book file is not uploaded to a backend.
